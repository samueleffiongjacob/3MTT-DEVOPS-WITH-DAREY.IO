# 3MTT Government DevOps Training Program

## Overview

The **3-Month Training (3MTT)** is a government-backed initiative designed to bridge the skills gap in the technology sector and prepare young professionals for high-demand roles in cloud infrastructure and DevOps engineering. This program leverages the **Darey.io** platform to deliver world-class, hands-on training in DevOps practices and technologies.

## About 3MTT

The 3-Month Training program is a flagship initiative sponsored by the Nigerian government to develop a skilled workforce in critical tech domains. The program focuses on:

- **Practical, industry-relevant skills**
- **Hands-on project-based learning**
- **Career readiness and professional development**
- **Job placement support and mentorship**

## DevOps Training Focus

This particular track concentrates on DevOps engineering, equipping participants with:

### Core Competencies

- **Infrastructure as Code (IaC):** Terraform, CloudFormation, Ansible
- **Containerization:** Docker and Docker Compose
- **Orchestration:** Kubernetes (K8s) fundamentals and advanced topics
- **CI/CD Pipelines:** Jenkins, GitLab CI/CD, GitHub Actions
- **Cloud Platforms:** AWS, Azure, and GCP essentials
- **Monitoring & Logging:** Prometheus, Grafana, ELK Stack
- **Version Control:** Git and collaborative workflows
- **Linux Administration:** Essential system administration skills

### Key Learning Outcomes

By the end of this training, participants will be able to:

✅ Design and deploy scalable infrastructure on cloud platforms  
✅ Automate deployment pipelines and reduce manual processes  
✅ Implement containerization and orchestration solutions  
✅ Set up monitoring, logging, and alerting systems  
✅ Apply security best practices in DevOps environments  
✅ Collaborate effectively using version control and DevOps tools  
✅ Build end-to-end CI/CD solutions for real-world applications

## Program Structure

### Duration
- **3 Months** (12 weeks) of intensive training
- Mix of self-paced learning and live instructor-led sessions
- Average commitment: 30-40 hours per week

### Modules

**Module 1: Foundations (Weeks 1-3)**
- Linux essentials and command-line mastery
- Version control with Git and GitHub
- Introduction to cloud computing concepts

**Module 2: Containerization & Orchestration (Weeks 4-6)**
- Docker fundamentals and advanced concepts
- Kubernetes architecture and deployment
- Container networking and storage

**Module 3: Infrastructure & Automation (Weeks 7-9)**
- Infrastructure as Code with Terraform
- Configuration management with Ansible
- Cloud platform essentials (AWS/Azure/GCP)

**Module 4: CI/CD & Monitoring (Weeks 10-12)**
- CI/CD pipeline design and implementation
- Monitoring, logging, and observability
- Capstone project: End-to-end DevOps solution
